Project at RPTU Kaiserslautern-Landau.

* Improved code-generation model quality to **85%** by fine-tuning LLaMA with parameter-efficient fine-tuning (PEFT) and curated synthetic Python data.
* Expanded the training data available for fine-tuning by generating and processing synthetic Python code covering additional programming patterns.
